# Project Dependencies

This file provides a comprehensive list of all dependencies used in the **Monitoring Dashboard** project, following the recent cleanup.

## Production Dependencies

### UI & UX (Radix UI + Tools)
- **@radix-ui/react-checkbox**: Accessible checkbox component.
- **@radix-ui/react-dialog**: Primitives for accessible modals, dialogs, and sheets.
- **@radix-ui/react-label**: Accessible form labels.
- **@radix-ui/react-scroll-area**: Custom scrollbar and scroll container.
- **@radix-ui/react-select**: Accessible select dropdown.
- **@radix-ui/react-separator**: Visual divider component.
- **@radix-ui/react-slider**: Accessible range slider input.
- **@radix-ui/react-slot**: Primitive for component composition (passing props to children).
- **@radix-ui/react-switch**: Accessible toggle switch.
- **@radix-ui/react-tabs**: Accessible tabbed interface navigation.
- **@radix-ui/react-toast**: Accessible notification system.
- **@radix-ui/react-toggle**: Accessible toggle button.
- **@radix-ui/react-tooltip**: Accessible hover information popups.
- **vaul**: An unstyled, accessible drawer component for mobile-friendly menus.
- **lucide-react**: A high-quality icon set for the UI.

### Framework & Core
- **next**: The React framework for production-grade web applications.
- **react** / **react-dom**: Core libraries for building the component-based user interface.
- **next-themes**: Seamless dark/light mode integration for Next.js.
- **zod**: TypeScript-first schema validation for data integrity.

### Data Visualization & Utilities
- **recharts**: Composable charting library for rendering market data trends.
- **date-fns**: Modern date utility library for formatting and manipulating timestamps.

### Styling
- **tailwindcss**: Utility-first CSS framework for rapid design execution.
- **tailwindcss-animate**: Plugin for easy entry/exit animations.
- **class-variance-authority (cva)**: CSS-in-JS utility for managing component variants.
- **clsx** / **tailwind-merge**: Utilities for managing and merging Tailwind CSS classes efficiently.
- **autoprefixer**: PostCSS plugin to handle vendor prefixes for CSS compatibility.

## Development Dependencies

- **typescript**: Static type checking for improved code quality and maintenance.
- **postcss**: Tool for transforming CSS with plugins.
- **@types/** (node, react, react-dom): TypeScript definitions for the core environment and libraries.
